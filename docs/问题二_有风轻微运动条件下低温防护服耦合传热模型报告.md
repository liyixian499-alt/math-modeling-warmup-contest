# 第 13 题问题二：有风轻微运动条件下低温防护服耦合传热模型改进报告

## 0. 报告目的与总体结论

问题二要求在问题一模型基础上，研究实验者在南极洲长城站外部环境温度

\[
T_\infty=-40^\circ\mathrm C
\]

保持不变，但外界风速提高至

\[
v=3\,\mathrm{m/s}
\]

且实验者由静止站立变为轻微运动时，防护服—人体系统的瞬态降温过程，并预测实验者何时必须返回室内。

问题二不需要重新建立一套与问题一无关的模型。三层防护服的材料属性、PCM 相变放热机理以及人体核心—皮肤热调节框架均可继承问题一。真正发生变化的是两个空气边界层和人体活动产热：

\[
\boxed{
h_{\rm in},\qquad
h_{\rm out},\qquad
M,\qquad
q_{\rm res}
}
\]

其中：

1. 轻微运动增强人体皮肤与内层织物之间空气层的等效对流换热；
2. \(3\,\mathrm{m/s}\) 外界风使外层隔热层与环境之间由自然对流主导转为强制对流主导；
3. 轻微运动提高人体代谢产热；
4. 呼吸显热和潜热损失随代谢率同步提高。

因此问题二的核心改进可以概括为：

\[
\boxed{
\text{问题一六状态人体—服装模型}
+
\text{运动增强内侧对流}
+
\text{风速驱动外侧强制对流}
+
\text{运动代谢修正}
}
\]

最终仍通过求解皮肤温度 \(T_s(t)\)，得到

\[
t_{15}
=
\inf\{t\ge0:T_s(t)\le15^\circ\mathrm C\},
\]

以及

\[
t_{10}
=
\inf\{t\ge0:T_s(t)\le10^\circ\mathrm C\}.
\]

问题二中“必须返回室内”的主要判据取

\[
\boxed{T_s=15^\circ\mathrm C}
\]

首次下降穿越时刻，即 \(t_{15}\)。

# 1. 问题二相对于问题一的条件变化

题目给定问题一环境为无风、静止站立，问题二改为：

\[
\boxed{
v=3\,\mathrm{m/s},
\qquad
\text{轻微运动}.
}
\]

题目同时明确指出：

- 内层织物与人体表面之间存在空气流动；
- 外层隔热层与外部环境之间存在空气流动；
- 空气流速改变会导致表面换热系数变化。

因此空气流动的影响不另行构造未知空气质量流量，而通过对流换热系数进入系统：

\[
\boxed{
\text{空气运动}
\rightarrow
h
\rightarrow
R_{\rm conv}
\rightarrow
q
\rightarrow
T(t).
}
\]

问题一到问题二的参数变化总结如下。

| 模型环节 | 问题一 | 问题二 | 是否修改机理 |
|---|---:|---:|---|
| 环境温度 \(T_\infty\) | \(-40^\circ\mathrm C\) | \(-40^\circ\mathrm C\) | 否 |
| 外界风速 \(v\) | \(0\) | \(3\,\mathrm{m/s}\) | 是 |
| 人体活动状态 | 静止站立 | 轻微运动 | 是 |
| 内侧换热 \(h_{\rm in}\) | \(3.0\) | \(4.0\,\mathrm{W/(m^2K)}\) | 参数更新 |
| 外侧换热 \(h_{\rm out}\) | 自然对流 | 自然/强制对流择大 | 边界条件更新 |
| 代谢率 \(M\) | \(70\) | \(93\,\mathrm{W/m^2}\) | 参数更新 |
| 呼吸散热 \(q_{\rm res}\) | 随 \(M=70\) | 随 \(M=93\) | 同步更新 |
| PCM 参数 | 问题一参数 | 不变 | 否 |
| 三层导热参数 | 问题一参数 | 不变 | 否 |
| 动态皮肤血流模型 | 六状态模型 | 继承 | 否 |

# 2. 继承问题一的六状态母模型

问题一最终采用人体核心—皮肤双节点与三层服装 RC 网络，并将实际皮肤血流作为独立动态状态。因此问题二继续使用状态向量

\[
\boxed{
\mathbf x
=
[T_c,T_s,T_1,T_2,T_3,\dot V_{bl}]^{\mathsf T}.
}
\]

其中：

- \(T_c\)：人体核心温度；
- \(T_s\)：人体平均皮肤温度；
- \(T_1\)：内层织物平均温度；
- \(T_2\)：PCM 功能层平均温度；
- \(T_3\)：外层隔热层平均温度；
- \(\dot V_{bl}\)：实际皮肤血流量。

完整热传递链仍为

\[
\boxed{
T_c
\rightarrow
T_s
\rightarrow
T_1
\rightarrow
T_2
\rightarrow
T_3
\rightarrow
T_\infty.
}
\]

问题二只改变链路两端的边界过程和人体代谢输入：

\[
\boxed{
M_{\rm act}
\rightarrow
T_c
\overset{q_{cs}}{\rightarrow}
T_s
\overset{q_{s1}(h_{\rm in})}{\rightarrow}
T_1
\rightarrow
T_2
\rightarrow
T_3
\overset{q_{3\infty}(v)}{\rightarrow}
T_\infty.
}
\]

同时核心节点存在呼吸散热旁路：

\[
T_c
\rightarrow
q_{\rm res}
\rightarrow
T_\infty.
\]

# 3. 基本假设

问题二继承问题一基本假设，并新增以下假设。

1. 防护服各材料层厚度、密度、导热系数和基础比热与问题一完全一致，风速和人体运动不改变材料本身物性。
2. 外界 \(3\,\mathrm{m/s}\) 风速在计算时间内视为恒定，其对外层表面的主要作用通过强制对流换热系数描述。
3. 未给出风向、人体朝向及局部绕流差异，因此采用人体/服装整体平均对流换热系数。
4. 题目未给出服装空气渗透率、开孔面积、通风量等数据，因此不额外引入
   \[
   \dot m_{\rm air}c_{p,a}\Delta T
   \]
   型空气穿透焓流；内部与外部空气运动均等效为表面对流换热。
5. 附件给出的“轻微运动”换热系数 \(4.0\,\mathrm{W/(m^2K)}\) 按问题一既有参数归属，用于人体皮肤—内层织物微气候层的等效对流换热。
6. 外层表面的强制对流采用 Fanger/ISO 7730 热平衡模型中的经验相关式
   \[
   h_{\rm forced}=12.1\sqrt{v}.
   \]
7. 自然对流与强制对流同时存在时，按照 Fanger/ISO 7730 模型取二者较大值。
8. “轻微运动”代谢率采用 ASHRAE Standard 55 中 standing, light activity 的典型值
   \[
   M_{\rm act}=93\,\mathrm{W/m^2}=1.6\,\mathrm{met}.
   \]
9. 未给定有效外部机械功，取
   \[
   W=0,
   \]
   即代谢产生的能量主要转化为人体内部热负荷。
10. 问题一中的动态皮肤血流、动态等效质量分区、质量交换焓流、PCM 表观热容及呼吸散热模型继续保留。

# 5. 内侧空气流动：轻微运动对皮肤—织物换热的修正

## 5.1 问题一内侧边界

问题一取静止站立条件下

\[
h_{\rm in,1}
=
3.0\,\mathrm{W/(m^2K)}.
\]

皮肤至内层织物中心的单位面积热阻为

\[
r_{s1}^{(1)}
=
\frac{1}{h_{\rm in,1}}
+
\frac{\delta_1}{2k_1}.
\]

对应热流密度

\[
q_{s1}^{(1)}
=
\frac{T_s-T_1}{r_{s1}^{(1)}}.
\]

---

## 5.2 问题二轻微运动修正

附件 2 给出轻微运动状态下对流换热系数

\[
\boxed{
h_{\rm in,2}
=
4.0\,\mathrm{W/(m^2K)}.
}
\]

因此

\[
\boxed{
r_{s1}^{(2)}
=
\frac{1}{4.0}
+
\frac{\delta_1}{2k_1}
}
\]

以及

\[
\boxed{
q_{s1}^{(2)}
=
\frac{T_s-T_1}{r_{s1}^{(2)}}.
}
\]

代入

\[
\delta_1=0.7\times10^{-3}\,\mathrm m,
\qquad
k_1=0.068\,\mathrm{W/(mK)}
\]

可得

\[
r_{s1}^{(1)}
\approx
0.33848\,\mathrm{m^2K/W},
\]

\[
r_{s1}^{(2)}
\approx
0.25515\,\mathrm{m^2K/W}.
\]

相应等效传热系数由

\[
\frac{1}{r_{s1}^{(1)}}\approx2.954\,\mathrm{W/(m^2K)}
\]

增加为

\[
\frac{1}{r_{s1}^{(2)}}\approx3.919\,\mathrm{W/(m^2K)}.
\]

在相同 \(T_s-T_1\) 下，皮肤向衣物传热能力约提高

\[
\boxed{
32.7\%.
}
\]

这表明轻微运动不仅提高人体产热，也会加强人体—服装微气候层的热交换。

# 6. 外侧空气流动：由自然对流升级为风致强制对流

## 6.1 自然对流项

附件 2 给出的无风自然对流关系为

\[
\boxed{
h_{\rm nat}
=
2.38|T_3-T_\infty|^{0.25}.
}
\]

其中：

- \(T_3\) 为外层隔热层表面温度；
- \(T_\infty=-40^\circ\mathrm C\)。

该式继续保留，因为有风环境下浮力自然对流并不会在物理上消失。

---

## 6.2 风速相关强制对流项

Fanger 人体热平衡模型以及 ISO 7730 所采用的经验关系为

\[
\boxed{
h_{\rm forced}
=
12.1\sqrt{v_{\rm ar}},
}
\]

其中：

- \(v_{\rm ar}\)：人体/服装表面与空气之间的相对速度，单位 \(\mathrm{m/s}\)；
- \(h_{\rm forced}\)：强制对流换热系数，单位 \(\mathrm{W/(m^2K)}\)。

系数 \(12.1\) 为人体/服装表面对流实验形成的经验系数，并非由本题数据反演所得。

由于题目直接给出外界风速

\[
v=3\,\mathrm{m/s},
\]

且没有人体运动速度和风向数据，主模型近似取

\[
\boxed{
v_{\rm ar}=3\,\mathrm{m/s}.
}
\]

于是

\[
h_{\rm forced}
=
12.1\sqrt 3
\approx
\boxed{
20.958\,\mathrm{W/(m^2K)}.
}
\]

---

## 6.3 自然对流与强制对流的统一处理

采用 Fanger/ISO 7730 的择大原则：

\[
\boxed{
h_{\rm out}
=
\max
\left[
2.38|T_3-T_\infty|^{0.25},
\,
12.1\sqrt{v_{\rm ar}}
\right].
}
\]

对于问题二：

\[
\boxed{
h_{\rm out}
=
\max
\left[
2.38|T_3+40|^{0.25},
\,
20.958
\right].
}
\]

初始时

\[
T_3(0)=37^\circ\mathrm C,
\]

自然对流项约为

\[
h_{\rm nat}(0)
=
2.38(77)^{0.25}
\approx
7.050\,\mathrm{W/(m^2K)}.
\]

显然

\[
20.958>7.050,
\]

因此问题二初期已经由强制对流占主导。随着 \(T_3\) 逐渐下降，自然对流项还会进一步降低，故在主要计算区间内预计均有

\[
\boxed{
h_{\rm out}\approx20.958\,\mathrm{W/(m^2K)}.
}
\]

程序仍应保留 `max` 形式，而不直接删除自然对流项。

# 7. 风速如何进入完整热量损失链路

问题二外侧热阻为

\[
\boxed{
r_{3\infty}^{(2)}
=
\frac{\delta_3}{2k_3}
+
\frac{1}{h_{\rm out}(v,T_3)}.
}
\]

外层向环境的热流密度为

\[
\boxed{
q_{3\infty}^{(2)}
=
\frac{T_3-T_\infty}
{r_{3\infty}^{(2)}}.
}
\]

于是风速与人体最终降温之间建立完整因果链：

\[
\boxed{
v
\rightarrow
h_{\rm forced}(v)
\rightarrow
h_{\rm out}
\rightarrow
r_{3\infty}
\rightarrow
q_{3\infty}
\rightarrow
T_3
\rightarrow
T_2
\rightarrow
T_1
\rightarrow
T_s.
}
\]

这正是问题二中“空气流动—热量损失”关系的核心数学表达。

# 11. 动态皮肤血流六状态模型保持不变

问题二继续使用问题一建立的有限响应时间皮肤血流模型。

目标血流为

\[
\boxed{
\dot V_{bl,\rm eq}(T_s)
=
\operatorname{clip}
\left(
\frac{6.3}
{1+0.5\max(0,33.7-T_s)},
0.5,90
\right).
}
\]

实际皮肤血流满足

\[
\boxed{
\frac{d\dot V_{bl}}{dt}
=
\frac{
\dot V_{bl,\rm eq}(T_s)-\dot V_{bl}
}{
\tau_{bl}
}.
}
\]

主模型继续采用问题一推荐值

\[
\boxed{
\tau_{bl}=173\,\mathrm s.
}
\]

皮肤等效质量分数

\[
\boxed{
\alpha_s
=
0.0417737
+
\frac{0.7451833}
{\dot V_{bl}+0.585417}.
}
\]

并有

\[
C_s=\alpha_sm_bc_b,
\]

\[
C_c=(1-\alpha_s)m_bc_b.
\]

由于问题二没有提供新的血流调节实验参数，因此不另外修改 \(\tau_{bl}\) 或目标血流关系，避免把“运动”同时重复计入代谢、换热和血流控制多个经验项。

# 12. 核心—皮肤热输运与质量交换焓流

核心—皮肤热流继续取

\[
\boxed{
q_{cs}
=
(5.28+1.163\dot V_{bl})(T_c-T_s).
}
\]

由

\[
\alpha_s
=
0.0417737
+
\frac{0.7451833}
{\dot V_{bl}+0.585417}
\]

有

\[
\frac{d\alpha_s}{d\dot V_{bl}}
=
-\frac{0.7451833}
{(\dot V_{bl}+0.585417)^2}.
\]

因此

\[
\boxed{
\dot\alpha_s
=
-\frac{0.7451833}
{(\dot V_{bl}+0.585417)^2}
\frac{
\dot V_{bl,\rm eq}(T_s)-\dot V_{bl}
}{
\tau_{bl}
}.
}
\]

等效质量交换率为

\[
\boxed{
\dot m_{cs}
=
m_b\dot\alpha_s.
}
\]

采用统一参考温度

\[
T_{\rm ref}=0^\circ\mathrm C,
\]

质量交换焓流继续定义为

\[

# 18. 数值求解方法

继续使用 `scipy.integrate.solve_ivp` 求解六状态 ODE。

推荐：

- 主求解器：`RK45`；
- 基准容差：`rtol=1e-7, atol=1e-9`；
- 加严复核：`DOP853` 或 `rtol=1e-9, atol=1e-11`；
- PCM 相变区域如出现明显刚性，可使用 `Radau` 对照。

每次 RHS 计算顺序建议为：

1. 读取
   \[
   T_c,T_s,T_1,T_2,T_3,\dot V_{bl};
   \]
2. 计算目标血流 \(\dot V_{bl,\rm eq}\)；
3. 计算 \(d\dot V_{bl}/dt\)；
4. 计算 \(\alpha_s,C_c,C_s,\dot\alpha_s\)；
5. 计算 \(q_{cs}\)；
6. 取问题二
   \[
   M=93
   \]
   并重新计算呼吸散热；
7. 取
   \[
   h_{\rm in}=4
   \]
   计算 \(q_{s1}\)；
8. 根据
   \[
   v=3
   \]
   计算 \(h_{\rm forced}\)；
9. 计算
   \[
   h_{\rm out}=\max(h_{\rm nat},h_{\rm forced});
   \]
10. 计算 \(q_{12},q_{23},q_{3\infty}\)；
11. 计算 PCM 表观热容；
12. 按 \(\dot\alpha_s\) 符号计算人体温度导数；
13. 返回六个状态导数。

# 24. 模型合理性与局限

## 24.1 合理性

问题二模型保留了问题一已经建立和校核的核心结构，只在有明确物理变化的环节修改参数和边界条件：

\[
\boxed{

+
\text{PCM 非线性储热}
+
\text{多层导热}
+
\text{内侧运动对流}
+
\text{外侧风致强制对流}.
}
\]

这种处理使问题一和问题二在数学结构上保持一致，便于直接比较 \(t_{15}\) 与 \(t_{10}\)。

---

## 24.2 主要局限

1. \(h_{\rm forced}=12.1\sqrt v\) 原本属于人体热舒适/人体热平衡经验相关式，本题在 \(-40^\circ\mathrm C\)、户外极寒环境下属于工况外推。
2. 模型使用整体平均风速，没有考虑人体前后侧、迎风面与背风面的局部换热差异。
3. 未考虑阵风，风速固定为 \(3\,\mathrm{m/s}\)。
4. 未给服装透气参数，因此没有模拟空气穿透服装后的质量交换和通风焓流。
5. \(93\,\mathrm{W/m^2}\) 是“standing, light activity”的典型代谢率，不是该实验者的直接代谢测量。
6. 轻微运动可能同时引起衣物摆动和空气泵吸效应，本模型仅通过 \(h_{\rm in}=4\) 等效表示。
7. 皮肤血流目标关系暂未额外加入代谢率项，以避免没有标定依据的重复修正。
8. 极寒环境下可能发生颤抖产热；若继续沿用问题一“不考虑颤抖”的设定，则计算结果仍具有偏保守属性。
