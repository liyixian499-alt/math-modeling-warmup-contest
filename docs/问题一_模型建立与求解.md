# 问题一：人体—三层防护服耦合传热模型的建立与求解

## 1. 问题重述与建模目标

在环境温度为

\[
T_a=-40\ ^\circ\mathrm C
\]

且人体静止、外界无风的条件下，建立人体与三层防护服之间的非稳态传热模型，计算皮肤平均温度随时间的变化，并确定

\[
t_{15}=\inf\{t:T_s(t)\le 15\ ^\circ\mathrm C\}
\]

和

\[
t_{10}=\inf\{t:T_s(t)\le 10\ ^\circ\mathrm C\}.
\]

其中，\(t_{15}\) 表示工作开始出现困难的时刻，\(t_{10}\) 表示达到危险阈值的时刻。本文按当前模型解释，将题目中的温度阈值施加于皮肤节点 \(T_s\)，同时输出核心温度 \(T_c\) 作为生理合理性检查量。

整体传热链写为

\[
\boxed{
M_0
\longrightarrow T_c
\longrightarrow T_s
\longrightarrow T_1
\longrightarrow T_2
\longrightarrow T_3
\longrightarrow T_a
}
\]

其中人体采用核心—皮肤双节点，防护服内层织物、中间相变层和外层隔热层分别采用一个集中参数节点。与固定热容量比例模型不同，本文进一步把皮肤等效质量比例 \(\alpha\) 作为动态状态，并显式计入核心与皮肤之间重新划分等效质量时携带的焓流。因此，模型共有六个状态变量：

\[
\boxed{
\boldsymbol y(t)=
[T_c,T_s,\alpha,T_1,T_2,T_3]^{\mathsf T}.
}
\]

---

## 2. 模型假设

1. 人体由温度均匀的核心节点和皮肤节点组成，三层服装各由一个温度均匀的中面节点表示。
2. 人体质量和人体等效比热在计算过程中保持不变；\(\alpha\) 表示皮肤及外围组织节点所占的**实际等效质量比例**，而不再只是经验性的热容量权重。
3. 当 \(\alpha\) 改变时，核心与皮肤之间发生双向等效质量交换。流出质量具有供体节点温度，进入接收节点后立即充分混合。
4. 基础代谢热全部产生于核心节点；静止工况下忽略颤抖产热和皮肤出汗蒸发，但保留呼吸显热与潜热损失。
5. 核心—皮肤常规传热由组织导热和稳态血液灌注组成；动态质量重新分配产生的焓流单独计算，不能再次包含于经验传热项中。
6. 服装各层材料均匀、各向同性，物性参数除相变层表观比热外均视为常数；层间接触热阻暂忽略。
7. 外界无风，外表面采用附件 2 给出的自然对流经验式；主模型暂不单独计算辐射、服装含湿和结霜效应。
8. 附件 1 的 DSC 曲线仅在给定基线和扫描速率假设后转换为过程相关的表观比热，不能将其表述为由附件严格、唯一确定的平衡态比热。

## 4. 人体核心—皮肤动态调节模型

### 4.1 皮肤冷信号与血流调节

取中性皮肤参考温度

\[
T_{s,0}=33.7\ ^\circ\mathrm C,
\]

定义皮肤冷信号

\[
\boxed{
\Phi_s=\max(0,T_{s,0}-T_s).
}
\]

低温条件下的皮肤血流量写为

\[
\boxed{
\dot V_{bl}
=\operatorname{clip}
\left(
\frac{6.3}{1+0.5\Phi_s},,0.5,,90
\right).
}
\]

核心—皮肤常规传热系数为

\[
\boxed{
G_{cs}=G_{\rm tissue}+G_{\rm perf}
=5.28+1.163\dot V_{bl}.
}
\]

于是，不含动态质量重新分配的核心—皮肤总热流为

\[
\boxed{
Q_{cs}^{(0)}=A_bG_{cs}(T_c-T_s).
}
\]

这里的 \(5.28\) 表示组织导热，\(1.163\dot V_{bl}\) 表示稳态血液灌注携热；后文的质量交换项仅表示动态等效边界移动，二者在物理定义上分开。

### 4.2 动态等效质量比例

依据当前采用的经验关系，定义目标皮肤等效质量比例

\[
\boxed{
\alpha_{\rm eq}
=0.0417737+
\frac{0.7451833}{\dot V_{bl}+0.585417}.
}
\]

直接令 \(\alpha=\alpha_{\rm eq}(T_s)\) 会使 \(\dot\alpha\) 与温度导数隐式耦合，并会在分段点附近产生突变。为此引入一阶响应过程：

\[
\boxed{
\tau_\alpha\dot\alpha
=\alpha_{\rm eq}-\alpha.
}
\]

基准可取

\[
\tau_\alpha=60\ \mathrm s,
\]

并在敏感性分析中考察 \(30\sim120\ \mathrm s\)。为避免某一节点的热容量趋近于零，限制

\[
0.05\le\alpha(t)\le0.75.
\]

数值实现时，在边界处只保留使 \(\alpha\) 返回可行区间的导数分量。需要强调：上述 \(\alpha_{\rm eq}\) 原本具有经验热权重性质；将其解释为实际等效质量比例，是本文为建立严格守恒的质量交换模型而增加的结构性假设。

### 4.3 核心与皮肤之间的等效质量交换

核心和皮肤的等效质量分别为

\[
m_c=(1-\alpha)m_b,
\qquad
m_s=\alpha m_b.
\]

定义两个方向均非负的质量交换率

\[
\boxed{
\dot m_{c\to s}=m_b\max(\dot\alpha,0),
}
\]

\[
\boxed{
\dot m_{s\to c}=m_b\max(-\dot\alpha,0).
}
\]

从而

\[
\dot m_s=\dot m_{c\to s}-\dot m_{s\to c}=m_b\dot\alpha.
\]

取统一参考温度 \(T_{\rm ref}\)，人体两节点的内能为

\[
U_c=(1-\alpha)m_bc_b(T_c-T_{\rm ref}),
\]

\[
U_s=\alpha m_bc_b(T_s-T_{\rm ref}).
\]

流动质量携带供体温度对应的焓，因而开口系统形式的守恒方程为

\[
\begin{aligned}
\frac{\mathrm dU_c}{\mathrm dt}
={}&Q_{\rm met}-Q_{\rm res}-Q_{cs}^{(0)}\\
&-c_b(T_c-T_{\rm ref})\dot m_{c\to s}
+c_b(T_s-T_{\rm ref})\dot m_{s\to c},
\end{aligned}
\]

\[
\begin{aligned}
\frac{\mathrm dU_s}{\mathrm dt}
={}&Q_{cs}^{(0)}-Q_{s1}\\
&+c_b(T_c-T_{\rm ref})\dot m_{c\to s}
-c_b(T_s-T_{\rm ref})\dot m_{s\to c}.
\end{aligned}
\]

两式相加后，核心—皮肤常规传热和质量交换焓流都严格抵消：

\[
\boxed{
\frac{\mathrm d(U_c+U_s)}{\mathrm dt}
=Q_{\rm met}-Q_{\rm res}-Q_{s1}.
}
\]

### 4.4 呼吸热损失

采用 Pierce 双节点模型常用的呼吸显热与潜热经验式：

\[
q_{\rm res}=q_{\rm res,sens}+q_{\rm res,lat},
\]

\[
\boxed{
q_{\rm res,sens}=0.0014M_0(34-T_a),
}
\]

\[
\boxed{
q_{\rm res,lat}=0.017251M_0(5.8662-p_a),
}
\]

其中 \(p_a\) 为空气水蒸气分压力，单位为 \(\mathrm{kPa}\)。在 \(-40\ ^\circ\mathrm C\) 下绝对含湿量很低，可在基准中近似取 \(p_a=0\)，得到

\[
q_{\rm res}\approx14.3\ \mathrm{W/m^2},
\qquad
Q_{\rm res}=A_bq_{\rm res}\approx23.7\ \mathrm W.
\]

该经验式在极端低温下属于外推，因此应同时设置呼吸损失倍率 \(\lambda_{\rm res}\)，实际计算使用 \(\lambda_{\rm res}q_{\rm res}\)，并对 \(\lambda_{\rm res}\) 做敏感性分析。

### 4.5 用于求解的人体温度方程

展开内能导数后，得到不含参考温度的显式方程：

\[
\boxed{
(1-\alpha)m_bc_b\dot T_c
=A_b\left[M_0-\lambda_{\rm res}q_{\rm res}
-G_{cs}(T_c-T_s)\right]
-c_b(T_c-T_s)\dot m_{s\to c}.
}
\]

\[
\boxed{
\alpha m_bc_b\dot T_s
=A_bG_{cs}(T_c-T_s)-Q_{s1}
+c_b(T_c-T_s)\dot m_{c\to s}.
}
\]

当 \(\dot\alpha>0\) 时，核心流出的质量与核心同温，故核心剩余部分不会因流出本身立即改变平均温度；进入皮肤的较热质量使皮肤获得额外混合热。当 \(\dot\alpha<0\) 时，较冷的皮肤等效质量进入核心，对核心产生额外冷却。

## 5. 三层防护服瞬态热阻—热容模型

### 5.1 皮肤至内层节点

皮肤至内层材料中面需要经过内侧空气间隙和半层内层织物，单位面积热阻为

\[
\boxed{
r_{s1}=\frac{1}{h_{\rm in}}+\frac{\delta_1}{2k_1}.
}
\]

取静止基准值

\[
h_{\rm in}=3.0\ \mathrm{W/(m^2K)}.
\]

皮肤向内层传递的总热流为

\[
\boxed{
Q_{s1}=A_b\frac{T_s-T_1}{r_{s1}}.
}
\]

内层质量和热容量为

\[
m_1=\rho_1\delta_1A_m,
\qquad
C_1=m_1c_1.
\]

### 5.2 内层至相变层

两个节点均位于材料中面，因此

\[
\boxed{
r_{12}=\frac{\delta_1}{2k_1}+\frac{\delta_2}{2k_2},
}
\]

\[
\boxed{
Q_{12}=A_m\frac{T_1-T_2}{r_{12}}.
}
\]

内层节点满足

\[
\boxed{
C_1\dot T_1=Q_{s1}-Q_{12}.
}
\]

### 5.3 相变层至外层

相变层与外层之间的单位面积热阻为

\[
\boxed{
r_{23}=\frac{\delta_2}{2k_2}+\frac{\delta_3}{2k_3},
}
\]

相应总热流为

\[
\boxed{
Q_{23}=A_m\frac{T_2-T_3}{r_{23}}.
}
\]

### 5.4 外层至环境

附件 2 给出的自然对流关系为

\[
\boxed{
h_o(T_3)=\lambda_h,2.38|T_3-T_a|^{0.25},
}
\]

其中基准取 \(\lambda_h=1\)。外层中面到环境的单位面积热阻为

\[
\boxed{
r_{3a}(T_3)=\frac{\delta_3}{2k_3}+\frac1{h_o(T_3)}.
}
\]

于是

\[
\boxed{
Q_{3a}=A_m\frac{T_3-T_a}{r_{3a}(T_3)}.
}
\]

在数值实现中，当 \(|T_3-T_a|\) 小于给定极小量时直接令 \(Q_{3a}=0\)，避免计算 \(1/h_o\) 时除零。

外层热容量和控制方程为

\[
C_3=\rho_3\delta_3A_mc_3,
\]

\[
\boxed{
C_3\dot T_3=Q_{23}-Q_{3a}.
}
\]

## 6. DSC 数据与相变层表观比热

### 6.1 DSC 曲线预处理

附件 1 只包含温度和 DSC 放热信号两列。设原始放热信号为 \(q_{\rm DSC}(T)\)，其单位为 \(\mathrm{mW/mg}\)，放热方向在文件中记为负值。取信号幅值

\[
d(T)=|q_{\rm DSC}(T)|.
\]

数据温区约为

\[
T_L=14.05\ ^\circ\mathrm C,
\qquad
T_U=26.018\ ^\circ\mathrm C.
\]

用两端点建立线性显热基线

\[
b(T)=d(T_L)+
\frac{d(T_U)-d(T_L)}{T_U-T_L}(T-T_L),
\]

并定义扣除基线后的纯相变峰

\[
\boxed{
q_{\rm ex}(T)=\max[d(T)-b(T),0].
}
\]

离散数据采用 PCHIP 保形插值，以避免普通高阶样条在峰值附近产生非物理振荡。在数据区间以外令 \(q_{\rm ex}(T)=0\)。

### 6.2 DSC 到表观比热的条件转换

若 DSC 扫描速率为 \(\beta\)，则单位质量潜热释放率满足

\[
\dot q_{\rm lat}=c_{\rm lat}(T)\beta.
\]

利用

\[
1\ \mathrm{mW/mg}=1000\ \mathrm{W/kg},
\]

得到

\[
\boxed{
c_{\rm app}(T)
=c_2+\lambda_L\frac{1000q_{\rm ex}(T)}{\beta},
}
\]

其中 \(\beta\) 必须以 \(\mathrm{K/s}\) 代入，\(\lambda_L\) 为材料潜热修正系数，基准取 1。

附件未直接给出扫描速率。由两端约 \(0.4\ \mathrm{mW/mg}\) 的基线信号和附件 2 的 \(c_2=2400\ \mathrm{J/(kg\,K)}\) 反推，可采用建模假设

\[
\boxed{
\beta_0=10\ \mathrm{K/min}=\frac16\ \mathrm{K/s}.
}
\]

因此基准表观比热为

\[
\boxed{
c_{\rm app}(T)=2400+6000q_{\rm ex}(T).
}
\]

经线性基线扣除后，对当前数据积分得到的辅助潜热估计约为

\[
\boxed{
L_{\rm DSC}
=\frac{1000}{\beta_0}
\int_{T_L}^{T_U}q_{\rm ex}(T)\,\mathrm dT
\approx122.3\ \mathrm{kJ/kg}.
}
\]

这个数值依赖于 \(\beta_0=10\ \mathrm{K/min}\)、线性基线和仪器信号已按质量归一化等假设。因此，严格表述应为：**附件 1 可以在这些假设下转换为本次温度扫描过程的等效表观比热，但附件本身不足以唯一确定材料的平衡热容。**

### 6.3 相变层控制方程

相变层质量为

\[
m_2=\rho_2\delta_2A_m.
\]

其温度相关有效热容量为

\[
C_{2,\rm eff}(T_2)=m_2c_{\rm app}(T_2).
\]

控制方程为

\[
\boxed{
m_2c_{\rm app}(T_2)\dot T_2=Q_{12}-Q_{23}.
}
\]

数值求解中不得再额外叠加独立的 \(Q_{\rm PCM}\) 放热源，否则会把同一潜热重复计算。

为进行严格的能量审计，定义相变层比焓

\[
\boxed{
H_{\rm app}(T)
=\int_{T_{\rm ref}}^T c_{\rm app}(\theta)\,\mathrm d\theta,
}
\]

则相变层内能为

\[
U_2=m_2H_{\rm app}(T_2).
\]

## 7. 最新耦合控制方程组

令

\[
\dot\alpha
=\frac{\alpha_{\rm eq}(T_s)-\alpha}{\tau_\alpha},
\]

并按边界约束修正其方向；再计算

\[
\dot m_{c\to s}=m_b\max(\dot\alpha,0),
\qquad
\dot m_{s\to c}=m_b\max(-\dot\alpha,0).
\]

问题一最终六状态方程组为

\[
\boxed{
\dot T_c=
\frac{
A_b[M_0-\lambda_{\rm res}q_{\rm res}-G_{cs}(T_c-T_s)]
-c_b(T_c-T_s)\dot m_{s\to c}
}{(1-\alpha)m_bc_b},
}
\]

\[
\boxed{
\dot T_s=
\frac{
A_bG_{cs}(T_c-T_s)-Q_{s1}
+c_b(T_c-T_s)\dot m_{c\to s}
}{\alpha m_bc_b},
}
\]

\[
\boxed{
\dot\alpha=
\frac{\alpha_{\rm eq}(T_s)-\alpha}{\tau_\alpha},
}
\]

\[
\boxed{
\dot T_1=\frac{Q_{s1}-Q_{12}}{\rho_1\delta_1A_mc_1},
}
\]

\[
\boxed{
\dot T_2=\frac{Q_{12}-Q_{23}}
{\rho_2\delta_2A_mc_{\rm app}(T_2)},
}
\]

\[
\boxed{
\dot T_3=\frac{Q_{23}-Q_{3a}}{\rho_3\delta_3A_mc_3}.
}
\]

其中

\[
\begin{aligned}
Q_{s1}&=A_b\frac{T_s-T_1}{r_{s1}},\\
Q_{12}&=A_m\frac{T_1-T_2}{r_{12}},\\
Q_{23}&=A_m\frac{T_2-T_3}{r_{23}},\\
Q_{3a}&=A_m\frac{T_3-T_a}{r_{3a}(T_3)}.
\end{aligned}
\]

该系统的主要非线性来自四部分：

\[
T_s\rightarrow\dot V_{bl}\rightarrow G_{cs},
\]

\[
T_s\rightarrow\alpha_{\rm eq}\rightarrow\alpha
\rightarrow\dot m_{c\leftrightarrow s},
\]

\[
T_2\rightarrow c_{\rm app}(T_2),
\]

\[
T_3\rightarrow h_o(T_3)\rightarrow r_{3a}(T_3).
\]

## 8. 初始条件与边界条件

环境阶跃边界为

\[
T_a(t)=-40\ ^\circ\mathrm C,\qquad t\ge0.
\]

由于题目没有同时给出平均皮肤温度和服装初温，必须明确初始状态假设。建议将以下状态作为生理合理的基准工况：

\[
\boxed{
T_c(0)=37\ ^\circ\mathrm C,
\qquad
T_s(0)=33.7\ ^\circ\mathrm C,
}
\]

\[
\boxed{
T_1(0)=T_2(0)=T_3(0)=20\ ^\circ\mathrm C,
}
\]

即防护服在进入低温环境前存放于普通室内。动态质量比例初值取当前温度对应的平衡值：

\[
\boxed{
\alpha(0)=\alpha_{\rm eq}[T_s(0)]\approx0.15.
}
\]

同时设置题面字面化的暖初值对照：

\[
T_c(0)=T_s(0)=T_1(0)=T_2(0)=T_3(0)=37\ ^\circ\mathrm C.
\]

后一情形相当于人体和服装均预热至 \(37\ ^\circ\mathrm C\)，通常应视为偏乐观的上限情景，而不是无需说明的自然初始状态。

## 9. 数值求解方法

### 9.1 单位统一与常数预计算

整个程序内部统一采用 SI 单位：

\[
t:\mathrm s,\quad
\delta:\mathrm m,\quad
Q:\mathrm W,\quad
c:\mathrm{J/(kg\,K)},\quad
\beta:\mathrm{K/s}.
\]

因此输入数据需要先完成

\[
\delta_i(\mathrm{mm})\times10^{-3}
\longrightarrow\delta_i(\mathrm m),
\qquad
\beta(\mathrm{K/min})\div60
\longrightarrow\beta(\mathrm{K/s}).
\]

将与温度无关的量预先计算，避免 ODE 求解器在每次调用右端函数时重复运算：

\[
\begin{aligned}
A_m&=\gamma_AA_b,\\
m_i&=\rho_i\delta_iA_m,\qquad i=1,2,3,\\
C_1&=m_1c_1,\qquad C_3=m_3c_3,\\
r_{s1}&=\frac1{h_{\rm in}}+\frac{\delta_1}{2k_1},\\
r_{12}&=\frac{\delta_1}{2k_1}+\frac{\delta_2}{2k_2},\\
r_{23}&=\frac{\delta_2}{2k_2}+\frac{\delta_3}{2k_3}.
\end{aligned}
\]

当 \(\gamma_A=1\) 时，基准数值约为

\[
\begin{aligned}
C_1&=1.156\times10^3\ \mathrm{J/K},\\
m_2c_2&=8.760\times10^2\ \mathrm{J/K},\\
C_3&=8.123\times10^2\ \mathrm{J/K},\\
r_{s1}&=0.33848\ \mathrm{m^2K/W},\\
r_{12}&=0.008480\ \mathrm{m^2K/W},\\
r_{23}&=0.006180\ \mathrm{m^2K/W}.
\end{aligned}
\]

这些服装节点热容量远小于人体热容量，说明系统包含明显不同的时间尺度，具有一定刚性。

### 9.2 DSC 数据预处理与插值

设 Excel 中共有 \(N\) 个有效数据点 \((T_j,q_j)\)。处理过程如下：

1. 删除空值和非数值记录，按 \(T_j\) 从小到大排序；若存在重复温度，则对对应 DSC 信号取平均值。
2. 按放热方向取幅值 \(d_j=|q_j|\)，用首尾点构造线性基线 \(b(T)\)。
3. 逐点计算

   \[
   q_{{\rm ex},j}=\max[d_j-b(T_j),0].
   \]

4. 对 \((T_j,q_{{\rm ex},j})\) 建立 PCHIP 保形插值函数 \(\widehat q_{\rm ex}(T)\)。
5. 在 \([T_L,T_U]\) 外令 \(\widehat q_{\rm ex}(T)=0\)，从而保证 \(c_{\rm app}\) 回到基础比热 \(c_2\)。
6. 采用梯形积分或 PCHIP 的分段积分计算

   \[
   L_{\rm DSC}
   =\frac{1000}{\beta}
   \int_{T_L}^{T_U}\widehat q_{\rm ex}(T)\,\mathrm dT,
   \]

   并检查基准值是否约为 \(122.3\ \mathrm{kJ/kg}\)。

程序中使用的表观比热函数为

\[
\boxed{
c_{\rm app}(T)=
c_2+\lambda_L\frac{1000}{\beta}
\begin{cases}
\widehat q_{\rm ex}(T),&T_L\le T\le T_U,\\
0,&\text{其他}.
\end{cases}
}
\]

由于基线扣除后两个端点的附加信号为零，该分段函数在 \(T_L,T_U\) 处连续；PCHIP 还能避免相变峰附近出现负值和过冲。

### 9.3 状态向量与右端函数

定义

\[
\boldsymbol y=
[T_c,T_s,\alpha,T_1,T_2,T_3]^{\mathsf T},
\qquad
\dot{\boldsymbol y}
=\boldsymbol f(t,\boldsymbol y;\boldsymbol p).
\]

给定某一时刻的状态，右端函数按以下顺序计算：

1. 由 \(T_s\) 计算 \(\Phi_s\)、\(\dot V_{bl}\)、\(G_{cs}\) 和 \(\alpha_{\rm eq}\)；
2. 计算未经边界修正的

   \[
   \dot\alpha_{\rm raw}
   =\frac{\alpha_{\rm eq}-\alpha}{\tau_\alpha};
   \]

3. 在 \(\alpha_{\min}\) 或 \(\alpha_{\max}\) 处投影 \(\dot\alpha_{\rm raw}\)，得到可行的 \(\dot\alpha\)；
4. 计算 \(\dot m_{c\to s}\) 与 \(\dot m_{s\to c}\)；
5. 计算呼吸热损失和四段总热流 \(Q_{s1},Q_{12},Q_{23},Q_{3a}\)；
6. 由 PCHIP 曲线求 \(c_{\rm app}(T_2)\)；
7. 代入六个控制方程并返回 \(\dot{\boldsymbol y}\)。

\(\alpha\) 的边界投影写为

\[
\dot\alpha=
\begin{cases}
0,&\alpha\le\alpha_{\min}
\ \text{且}\ \dot\alpha_{\rm raw}<0,\\
0,&\alpha\ge\alpha_{\max}
\ \text{且}\ \dot\alpha_{\rm raw}>0,\\
\dot\alpha_{\rm raw},&\text{其他}.
\end{cases}
\]

引入 \(\alpha\) 的动态方程后，右端关于当前状态是显式的，不需要在每个时间步中联立求解 \(\dot\alpha,\dot T_c,\dot T_s\)。

### 9.4 刚性 ODE 求解器

服装节点热惯性较小，而人体节点热惯性较大；相变区又使 \(C_{2,\rm eff}\) 随温度显著变化。因此使用显式欧拉法需要很小步长，稳定性和阈值时刻精度均不理想。主计算建议采用隐式 Runge–Kutta Radau IIA 方法；BDF 可作为交叉验证。

设置

\[
t\in[0,t_{\max}],
\qquad
t_{\max}=24\ \mathrm h=86400\ \mathrm s,
\]

\[
\boxed{
\mathrm{rtol}=10^{-8},
\qquad
\mathrm{atol}=10^{-10},
\qquad
\Delta t_{\max}=2\ \mathrm s.
}
\]

这里的 \(\Delta t_{\max}\) 只是允许的最大内部步长，实际步长由求解器根据局部截断误差自动调整。若计算成本较高，可先用 \(5\ \mathrm s\) 得到初步结果，再用 \(2\ \mathrm s\) 和 \(1\ \mathrm s\) 做收敛复核。

若使用 SciPy，可写为

~~~python
sol = solve_ivp(
    fun=rhs,
    t_span=(0.0, 86400.0),
    y0=y0,
    method="Radau",
    rtol=1e-8,
    atol=1e-10,
    max_step=2.0,
    events=(event_15, event_10),
    dense_output=True,
)
~~~

Radau 的自适应步长用于积分，dense output 仅用于绘图和统一时刻输出，不用线性插值替代求解器的事件定位。

### 9.5 阈值事件定位

定义两个连续事件函数

\[
g_{15}(t,\boldsymbol y)=T_s-15,
\qquad
g_{10}(t,\boldsymbol y)=T_s-10.
\]

两个事件均只检测从正到负的下降穿越：

~~~python
def event_15(t, y):
    return y[1] - 15.0

def event_10(t, y):
    return y[1] - 10.0

event_15.direction = -1
event_15.terminal = False
event_10.direction = -1
event_10.terminal = True
~~~

由求解器返回的第一次事件时刻确定

\[
t_{15}=t_{{\rm event},15}^{(1)},
\qquad
t_{10}=t_{{\rm event},10}^{(1)}.
\]

若在 \(t_{\max}\) 内没有触发某一事件，则结果应报告为 \(t_{15}>t_{\max}\) 或 \(t_{10}>t_{\max}\)，不能把 \(t_{\max}\) 本身误写成阈值时刻。

### 9.6 接近 Python 实现的完整伪代码

~~~python
# 1. 读取并预处理 DSC
T_dsc, q_dsc = read_excel(...)
T_dsc, q_dsc = sort_merge_duplicate(T_dsc, q_dsc)
baseline = line_through_endpoints(T_dsc, abs(q_dsc))
q_ex_data = maximum(abs(q_dsc) - baseline(T_dsc), 0.0)
q_ex_pchip = PchipInterpolator(T_dsc, q_ex_data, extrapolate=False)

def q_ex(T):
    if T < T_L or T > T_U:
        return 0.0
    return max(float(q_ex_pchip(T)), 0.0)

def c_app(T, beta, lambda_L):
    return c2 + lambda_L * 1000.0 * q_ex(T) / beta

# 2. 六状态方程右端
def rhs(t, y):
    Tc, Ts, alpha, T1, T2, T3 = y

    cold = max(33.7 - Ts, 0.0)
    v_bl = clip(6.3 / (1.0 + 0.5 * cold), 0.5, 90.0)
    G_cs = 5.28 + 1.163 * v_bl
    alpha_eq = 0.0417737 + 0.7451833 / (v_bl + 0.585417)

    alpha_dot = (alpha_eq - alpha) / tau_alpha
    if alpha <= alpha_min and alpha_dot < 0.0:
        alpha_dot = 0.0
    if alpha >= alpha_max and alpha_dot > 0.0:
        alpha_dot = 0.0

    m_c_to_s = mb * max(alpha_dot, 0.0)
    m_s_to_c = mb * max(-alpha_dot, 0.0)

    h_out = lambda_h * 2.38 * abs(T3 - Ta) ** 0.25
    if abs(T3 - Ta) < eps_T:
        Q_3a = 0.0
    else:
        r_3a = delta3 / (2.0 * k3) + 1.0 / h_out
        Q_3a = A_m * (T3 - Ta) / r_3a

    Q_s1 = A_b * (Ts - T1) / r_s1
    Q_12 = A_m * (T1 - T2) / r_12
    Q_23 = A_m * (T2 - T3) / r_23

    dTc = (
        A_b * (M0 - lambda_res * q_res - G_cs * (Tc - Ts))
        - cb * (Tc - Ts) * m_s_to_c
    ) / ((1.0 - alpha) * mb * cb)

    dTs = (
        A_b * G_cs * (Tc - Ts) - Q_s1
        + cb * (Tc - Ts) * m_c_to_s
    ) / (alpha * mb * cb)

    dT1 = (Q_s1 - Q_12) / C1
    dT2 = (Q_12 - Q_23) / (m2 * c_app(T2, beta, lambda_L))
    dT3 = (Q_23 - Q_3a) / C3

    return [dTc, dTs, alpha_dot, dT1, dT2, dT3]

# 3. 设定初值、调用 Radau，并读取 t15、t10
y0 = [37.0, 33.7, alpha0, 20.0, 20.0, 20.0]
sol = solve_ivp(
    rhs,
    (0.0, 86400.0),
    y0,
    method="Radau",
    rtol=1e-8,
    atol=1e-10,
    max_step=2.0,
    events=(event_15, event_10),
    dense_output=True,
)
t15 = first_event_or_none(sol.t_events[0])
t10 = first_event_or_none(sol.t_events[1])
~~~

其中 \(q_{\rm res}\) 在给定 \(M_0,T_a,p_a\) 后预先计算；若敏感性分析改变 \(M_0\)，必须同步更新 \(q_{\rm res}\)。程序中的 \(\beta\) 使用 \(\mathrm{K/s}\)，基准值为 \(10/60\)。

### 9.7 数值收敛与误差判据

分别取

\[
\Delta t_{\max}=5,\ 2,\ 1\ \mathrm s
\]

重复计算，并定义

\[
\varepsilon_{15}
=\frac{|t_{15}^{(1\,{\rm s})}-t_{15}^{(2\,{\rm s})}|}
{t_{15}^{(1\,{\rm s})}},
\qquad
\varepsilon_{10}
=\frac{|t_{10}^{(1\,{\rm s})}-t_{10}^{(2\,{\rm s})}|}
{t_{10}^{(1\,{\rm s})}}.
\]

建议以

\[
\boxed{
\varepsilon_{15}<10^{-3},
\qquad
\varepsilon_{10}<10^{-3}
}
\]

作为阈值时间的数值收敛标准。

能量守恒不宜直接对离散内能作数值微分，而应采用积分形式。人体子系统的累计能量误差为

\[
\Delta E_{\rm human}(t)
=U_c(t)+U_s(t)-U_c(0)-U_s(0)
-\int_0^t
\left[A_b(M_0-\lambda_{\rm res}q_{\rm res})-Q_{s1}\right]
\,\mathrm d\tau.
\]

完整系统的累计误差为

\[
\begin{aligned}
\Delta E_{\rm all}(t)
={}&U_{\rm all}(t)-U_{\rm all}(0)\\
&-\int_0^t
\left[A_b(M_0-\lambda_{\rm res}q_{\rm res})-Q_{3a}\right]
\,\mathrm d\tau.
\end{aligned}
\]

用梯形积分计算右端累计热量，并用总输入、输出热量的较大者归一化。基准计算建议满足

\[
\boxed{
\max_t
\frac{|\Delta E_{\rm all}(t)|}
{\max\left(
\int_0^t|A_b(M_0-\lambda_{\rm res}q_{\rm res})|\,\mathrm d\tau,\,
\int_0^t|Q_{3a}|\,\mathrm d\tau,\,
1\ \mathrm J
\right)}
<10^{-4}.
}
\]

\[
\boxed{
\text{读取 DSC}
\rightarrow
\text{统一单位并扣除基线}
\rightarrow
\text{PCHIP 与 }c_{\rm app}
\rightarrow
\text{预计算常数}
\rightarrow

\rightarrow

\rightarrow
\text{能量审计与步长收敛}
\rightarrow
\text{敏感性分析}.
}
\]

## 10. 模型检验

### 10.1 质量守恒

每个输出时刻均应满足

\[
\boxed{
m_c+m_s=(1-\alpha)m_b+\alpha m_b=m_b.
}
\]

同时检查

\[
0.05\le\alpha(t)\le0.75.
\]

### 10.2 人体子系统能量守恒

定义残差

\[
\boxed{
r_{\rm human}
=\frac{\mathrm d(U_c+U_s)}{\mathrm dt}
-Q_{\rm met}+Q_{\rm res}+Q_{s1}.
}
\]

数值结果应满足 \(r_{\rm human}\approx0\)。若残差中出现与 \(\dot\alpha\) 同步的尖峰，通常说明遗漏了质量迁移焓流或把迁移项符号写反。

### 10.3 完整系统能量守恒

令

\[
U_1=m_1c_1(T_1-T_{\rm ref}),
\qquad
U_3=m_3c_3(T_3-T_{\rm ref}),
\]

\[
U_2=m_2H_{\rm app}(T_2),
\]

则完整人体—服装系统应满足

\[
\boxed{
\frac{\mathrm d}{\mathrm dt}
(U_c+U_s+U_1+U_2+U_3)
=A_b(M_0-\lambda_{\rm res}q_{\rm res})-Q_{3a}.
}
\]

内部热流 \(Q_{cs}^{(0)}\)、\(Q_{s1}\)、\(Q_{12}\)、\(Q_{23}\) 和质量交换焓流必须两两抵消。

### 10.4 DSC 焓增量检查

检查

\[
\int_{T_L}^{T_U}[c_{\rm app}(T)-c_2],\mathrm dT
=\lambda_LL_{\rm DSC}.
\]

若在 ODE 中又加入额外潜热源，上式与完整系统能量审计会同时显示潜热重复计入。

### 10.5 数值与结构退化检查

1. 将最大步长依次减半，确认 \(t_{15}\) 和 \(t_{10}\) 的相对变化足够小。
2. 令 \(q_{\rm ex}=0\)，模型应退化为中间层常比热模型。
3. 令 \(\dot\alpha=0\)，质量交换项应自动消失，并退化为固定质量分配的五温度节点模型。
4. 分别关闭 \(G_{\rm perf}=1.163\dot V_{bl}\) 和质量重新分配项，比较结果，以排查两类血流相关效应是否被经验参数重复放大。

## 11. 敏感性与稳健性分析

建议以 \(t_{15}\) 为主要响应量、\(t_{10}\) 为次要响应量，分组进行单因素分析或采用统一的拉丁超立方抽样。局部归一化敏感度可定义为

\[
S_p=
\frac{\Delta t/t_0}{\Delta p/p_0}.
\]

推荐参数分组如下。

| 类别 | 参数或情景 | 推荐取值 | 说明 |
| --- | --- | --- | --- |
| 初始状态 | \(T_s(0)\)、\(T_{1,2,3}(0)\) | 皮肤 33.7/37；服装 20/37 °C | 区分生理初值和预热上限 |
| 人体产热 | \(M_0\) | 60、70、80 \(\mathrm{W/m^2}\) | 同步重算呼吸热损失 |
| DSC 换算 | \(\beta\) | 9、10、11 \(\mathrm{K/min}\) | 固定记录曲线，反映扫描速率识别误差 |
| 材料潜热 | \(\lambda_L\) | 0.8、1.0、1.2 | 固定 \(\beta=10\ \mathrm{K/min}\) 后单独改变 |
| 内侧换热 | \(h_{\rm in}\) | 2、3、4 \(\mathrm{W/(m^2K)}\) | 当前模型中通常是高敏感参数 |
| 外侧换热 | \(\lambda_h\) | 0.8、1.0、1.2 | 修正自然对流经验式 |
| 呼吸散热 | \(\lambda_{\rm res}\) | 0.5、1.0、1.5 | 反映极低温外推误差 |
| 质量调节 | \(\tau_\alpha\) | 30、60、120 s | 反映血管调节响应速度 |
| 模型结构 | 固定/动态 \(\alpha\) | 固定 0.15、动态；另列旧模型 0.10 | 验证新增质量交换机制的贡献 |
| 服装面积 | \(\gamma_A\) | 1.0、1.25 | 只作结构情景，不与人体面积混淆 |

其中 \(\beta\) 与 \(L\) 不能在同一组分析中被当成完全独立的自由参数。由同一条 DSC 曲线计算时

\[
L_{\rm DSC}\propto\frac1\beta.
\]

因此应采用以下两种互斥方案：

1. **DSC 换算不确定性：**只改变 \(\beta\)，同步重算 \(c_{\rm app}\) 与 \(L_{\rm DSC}\)；
2. **材料批次不确定性：**固定 \(\beta=10\ \mathrm{K/min}\)，只改变 \(\lambda_L\)。

这样可以避免对同一潜热不确定性进行重复扰动。

## 12. 模型输出与结果表达

一次基准计算至少应输出：

1. \(T_c,T_s,T_1,T_2,T_3\) 的时间历程；
2. \(\alpha\)、\(\dot V_{bl}\) 和 \(G_{cs}\) 的时间历程；
3. \(Q_{\rm res},Q_{cs}^{(0)},Q_{s1},Q_{12},Q_{23},Q_{3a}\) 的时间历程；
4. 相变层进入和离开 DSC 有效温区的时刻；
5. \(t_{15}\) 与 \(t_{10}\)；
6. 人体和完整系统的最大绝对能量残差；
7. 各敏感性情景相对基准值的变化率。

最终可将模型概括为

\[
\boxed{
\text{守恒型核心—皮肤质量交换双节点}
+\text{三层服装瞬态 RC 网络}
+\text{DSC 表观比热相变模型}
+\text{非线性自然对流边界}.
}
\]

相较于原五节点固定热容量模型，本模型的实质改进不是简单地把 \(\alpha=0.1\) 替换为 \(\alpha(t)\)，而是在重新解释 \(\alpha\) 的物理意义后，引入其动态方程和双向质量焓流，从而保证核心与皮肤之间重新划分等效质量时，人体总能量仍严格守恒；同时，核心方程正式保留呼吸散热，使极寒环境下的热损失描述更完整。
