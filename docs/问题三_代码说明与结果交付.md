# 问题三代码说明与结果交付

## 1. 交付结论

本程序已在问题一六状态动态皮肤血流模型上完成外层涂层整数优化。100 kg 表示不包括人体自重的总外部承重上限，因此硬约束检查整套防护服质量；时间惩罚以问题一为基准，只作用于新增质量。

$$
J(N)=t_{15}(N)-20[m(N)-m(1)].
$$

最优方案是外层总计 **4 层**，即在原防护服上新增 **3 层**，外层总厚度 **1.2 mm**。

- 问题一基准时间：678.621 min；
- 最优方案纯传热时间：735.001 min；
- 新增重量惩罚：11.152 s；
- 题意主口径站立时间评分：734.815 min；
- 相对问题一净增益：56.194 min；
- 核心 $35^\circ\mathrm C$ 安全修正评分：271.037 min。

## 2. 代码结构

- `src/问题三/config.py`：决策、成本、质量、预算和承重约束；
- `src/问题三/model.py`：多外层温度节点和人体—防护服 ODE；

- `src/问题三/workflow.py`：统一运行枚举、严格复核、敏感性、CSV 导出和报告生成。

## 9. 已知边界与后续建议

- 负重代谢系数和压迫换热系数未由题目数据标定，故仅作情景分析；
- 基准服装初始温度为 $37^\circ\mathrm C$，实际未预热服装应参考初温敏感性结果；
- 主模型未包含风、辐射、结霜、水分迁移、冷桥和制造公差；
- 若有实验数据，优先标定代谢率、内侧换热系数和层间接触热阻。
