# 参考文献检索、核验与引用审计报告

## 1. 审计结论

本轮围绕论文实际使用的人体热调节、人体—防护服耦合传热、PCM 调温服装、DSC 热物性处理、等效热容、风致对流、自适应 ODE 事件积分、局部敏感性与整装量化设计开展检索与核验。最终保留 13 篇正式期刊论文，并已按正文首次出现顺序写入 `paper/main.tex` 和 `paper/references.bib`。

## 6. 未纳入的旧条目

原参考文献中的 1986、1988、2013、2017 年论文/标准和 2017 年血流研究均因年份硬约束移除；2022 年 EnergyPlus 技术报告虽满足年份下限，但不是期刊论文，且会破坏本轮“正式学术论文”口径，也已移除。正文原先把多个经验常数直接归因给这些旧条目，本轮改为区分“近期研究支持的模型结构”与“本文采用的参数设定”，避免将新文献冒充经典模型的原始来源。
